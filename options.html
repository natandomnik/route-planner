Szczegóły: Rozpoznawanie trasy przez AI

Twoja instrukcja zastępuje domyślną i obowiązuje dla wszystkich dostawców. Kliknij „Zapisz ustawienia”, aby zachować ją na kolejne uruchomienia.

Model nadal musi zwracać JSON z polami points i warnings. Tekst trasy dostaje osobno. Test połączenia używa instrukcji aktualnie widocznej w tym polu.

Wymagany format odpowiedzi (JSON Schema)


Wtyczka sprawdza format odpowiedzi i pokazuje punkty do korekty. Nie sprawdza geograficznej poprawności kodów.





Szczegóły: Sprawdzanie kodów przy kopiowaniu

Moduł automatycznie weryfikuje kody pocztowe w internecie podczas kopiowania punktów trasy do schowka (wykorzystuje model Groq). Skopiowany tekst zawiera zweryfikowane kody, podczas gdy edytowane punkty trasy w oknie wtyczki pozostają nienaruszone.


Do działania wyszukiwania kodów wymagany jest klucz API Groq skonfigurowany w sekcji dostawców AI.





Szczegóły: Sugestie obszarów przy A/B



Wybierz model do wyszukiwania obszarów poszukiwań wokół punktów A i B. Na liście wyświetlane są modele tych dostawców, dla których skonfigurowano klucze API.

Testuje wybranego dostawcę, klucz i model, bez zapisywania zmian. Wysyła krótką przykładową trasę, bez danych Twojego zlecenia. Test zużywa niewielką liczbę tokenów API.
